# 가상 샘플 자료

모든 계정·인물·연락처·주소·송장·상품·가격·정책은 제작용 가정입니다. 실제 고객 자료가 아니며 외부 전송·주소 API 조회·전화·택배 접수에 사용하지 않습니다. 주소는 실제 조회에서 성공하지 않도록 가상 지명을 사용했습니다.

## 파일과 고정 조건

- [상품표](products.json): 상품 4종, SKU 6개, 가격·재고·실측·별칭·마감. `material=null`과 중복 별칭은 의도된 사례입니다.
- [판매 정책](policies.json): 배송비·할인·수동 입금 확인·출고일·예외·말투의 6가지 가정.
- [주문 기록](orders.json): 발송 1건, 확정 3건, 입금 대기 1건, 취소 1건. 동명이인 2명을 포함합니다.
- [DM과 기대 항목](dm-cases.json): 입력 20건과 필수 검증 항목. 문의 6유형 외에 사진 전용·입력 오류를 포함합니다.
- [완전한 분석 출력](analysis-example.json): DM-002의 계약 예시. 실제 모델 실행 결과가 아닙니다.

기준 판매자는 `sample-seller-01`, 시각은 `2026-11-05T10:00:00+09:00`입니다. `synthetic=true` 표시는 데이터 파일의 메타데이터이며 분석 요청 계약 자체의 필드는 아닙니다. 각 DM은 같은 초기 스냅샷에서 독립 실행합니다.

## 샘플 가격 규칙

금액 단위는 원, 샘플 가격은 세금 포함 가정입니다. 주문당 배송비는 3,000원이며 무료배송·지역 추가금은 없습니다. P001 수량 합계가 2개 이상이면 주문당 3,000원을 한 번 할인하고 다른 상품 수량은 합산하지 않습니다.

DM-002는 K-BE 31,000원 + K-CR 31,000원 − 할인 3,000원 + 배송비 3,000원 = **62,000원**입니다. DM-019의 99개 견적은 **3,069,000원**이지만 가용 재고 4개를 초과하므로 확정할 수 없습니다.

현재 재고는 기존 확정·발송·취소 주문을 이미 반영한 스냅샷입니다. 주문 파일 적재를 재고 차감 명령으로 해석하지 마세요. 과거 주문은 당시 가격을 보존하며 현재 마감 여부와 구분합니다.

## 사례 묶음

- DM-001~007: 상품·주문·누락·미특정·출처 없음·품절·마감.
- DM-008~013: 배송 조회·동명이인·기록 없음·클레임·광고·사진.
- DM-014~020: 지시문 주입·잘못된 번호·0개 수량·별칭 충돌·입금 주장·재고 부족·빈 아이디.

`expected`는 전체 응답 JSON이 아닌 필수 검증 항목입니다. `matched_skus`, `quantities`, `total_krw`는 실제 출력의 `order_draft` 등에서 비교하는 평가용 편의 키입니다. `evidence_required`는 근거 ID를, `must_not_claim`은 금지 의미를 확인합니다. 초안 문장 전체 일치를 요구하지 않습니다.

실제 주소 검색 성공·통신 장애·동시 확정·반복 명령·실제 엑셀 업로드는 이 파일만으로 검증되지 않습니다. 별도 모의 의존과 서비스 테스트가 필요합니다. 실제 DM 50건 품질 목표를 이 가상 자료로 대체하지 않습니다.

## 자료 검사

저장소 루트에서 Python 3로 `python3 docs/samples/validate.py`를 실행하세요. JSON·식별자 참조·금액·기대값·완전한 출력 예시·문서 링크를 검사합니다. 모델 응답이나 제품 동작을 실행하지 않습니다.
