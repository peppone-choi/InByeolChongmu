# 제품 요구 문서 (PRD)

상태: 초안 · 2026-11-05 · 근거: [초기 기획](planning.md)

## 대상과 문제

인스타그램 DM으로 상품과 공동구매를 판매하는 1인 셀러가 대상입니다. 대화에서 상품 정보를 찾고 주문을 엑셀에 옮기며 송장 자료를 다시 입력하는 반복 업무를 줄입니다. 대상은 아직 가상 고객이며 실제 수요를 검증하지 않았습니다.

## 제품 목표

고객 아이디와 텍스트 DM을 넣으면 상품·정책·주문 근거가 붙은 초안과 주문 후보를 얻습니다. 판매자는 답장을 직접 보내고, 입금을 확인해 주문을 확정합니다. 확정 주문을 조회하거나 택배 양식으로 내보냅니다.

## 첫 버전 범위

- 단건·여러 건 DM 입력과 6가지 문의 유형 분류.
- 근거 기반 초안, 필수 주문 정보 추출·누락 안내, 코드 금액 계산.
- 판매자 승인 후 주문 기록·재고 반영, 주문 조회, 수동 발송·송장 등록 및 정정.
- 확정 주문의 택배사 일괄 등록 양식 내보내기.

## 제외 범위

인스타그램 직접 연동·자동 발송, 은행 자동 확인, 택배사 API 송장 발급, 사진 인식, 다계정·다인원, 홍보 글·쇼핑몰·결제 기능을 제외합니다. 환불·보상·마감 예외는 판매자가 결정합니다.

## 가치와 성공 판정

원문의 DM 50건 목표: 분류 정확도 90% 이상, 초안 사용 가능 비율 70% 이상, 근거 없는 정보 생성 0건, 추출 필드 정확도 95% 이상, 필수 정보 누락 감지율 100%입니다. 가상 40건의 결과로 이 목표를 달성했다고 판단하지 않습니다.

실사용 1주 목표는 주문 조회 평균 30초 이내, DM 대응 시간 도입 전의 절반 이하, 주소·연락처 오타 배송 사고 0건입니다. 도입 전후 시간을 실제 측정해야 하며 모두 미검증입니다.

## 핵심 위험과 다음 확인

복사·붙여넣기와 검토 부담이 절감 효과보다 클 수 있습니다. 실제 셀러의 흐름, 판매 정책, 택배 양식으로 검증합니다. 상세 동작은 [요구사항](requirements.md), 완료 여부는 [인수조건](acceptance-criteria.md)에서 관리합니다.
