# 인별총무 (InByeolChongmu)

인스타그램 DM으로 상품을 판매하는 1인 셀러를 위해, 답장 초안 작성부터 주문 정리와 송장 입력 자료 준비까지 돕는 에이전트를 기획합니다.

## 누구를 위한 에이전트인가요?

옷이나 생활용품을 DM으로 판매하거나 공동구매를 운영하며, 하루 수십 건의 문의를 혼자 처리하는 판매자를 대상으로 합니다. DM 내용을 엑셀에 옮기고, 주문과 송장을 찾아 고객에게 답하는 반복 업무를 줄이는 것이 목표입니다.

현재는 가상 고객을 바탕으로 한 기획이며, 실제 판매자의 수요와 시간 절감 효과는 아직 검증하지 않았습니다.

## 어떤 업무를 대신하나요? (구현 예정)

- 복사해 붙여넣은 텍스트 DM을 문의 유형별로 분류합니다.
- 상품표·판매 정책·주문 기록을 근거로 판매자 말투의 답장 초안을 작성합니다.
- 주문 정보를 추출하고, 빠진 필수 정보를 안내합니다.
- 판매자가 입금을 확인하고 승인한 주문을 기록하고, 아이디나 이름으로 조회합니다.
- 확정 주문을 택배사 일괄 등록용 엑셀 양식으로 내보냅니다.

답장은 판매자가 검토 후 직접 보냅니다. 입금 확인과 주문 확정도 판매자가 맡습니다. 송장 자료 내보내기는 송장 자동 발급이나 프린터 출력과 다릅니다.

## 진행 상황

**2026-11-05 기준: 기획 단계입니다. 실행 가능한 에이전트 기능은 아직 없습니다.**

### 지금 되는 것

- 저장소 기여 지침과 필수 문서 점검 규칙을 확인할 수 있습니다.
- [초기 기획서](docs/planning.md)에서 대상 업무, 첫 버전 범위, 검증 목표와 미정 사항을 확인할 수 있습니다.
- 같은 기획서에서 유사 서비스 피드백과 JSON 추출·코드 검증·상품 별칭·주소 검색 API 검토 방향을 확인할 수 있습니다. 모두 미구현 제안입니다.

### 아직 안 되는 것

- DM 입력·분류, 답장 생성, 주문 추출·저장·조회, 재고 반영, 엑셀 내보내기 모두 미구현입니다.
- 상품표·정책·주문 기록 연결, 실행 화면, 모델 호출, 테스트 환경이 없습니다.
- 설치·실행·빌드 명령어와 기술 스택은 아직 정해지지 않았습니다.

### 첫 버전에서 제외하는 것

인스타그램 직접 연동·자동 발송, 은행 입금 자동 확인, 택배사 API 송장 발급, 사진 인식, 다계정·다인원 지원, 홍보 글 작성, 결제·쇼핑몰 기능은 다루지 않습니다.
